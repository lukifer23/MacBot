# MacBot modernization review

Reviewed November 23, 2026 against [main at 08e8ba4](https://github.com/lukifer23/MacBot/commit/08e8ba4fa4350fb127825c674475b13ea47fb49b). This branch is a software checkpoint. Model, runtime installation, microphone, speaker, desktop action, and physical-device acceptance are pending.

## Product direction

MacBot should be a native, local-first workspace for talking, dictating, researching a private library, and carrying out authorized Mac actions. Users should be able to tell whether MacBot is listening, where its information came from, and exactly what it is asking to do. Text and hands-free conversation share a history. Durable jobs expose the plan, authority, progress, and evidence across reconnects. One local app owns audio and native permissions. The Python runtime owns inference scheduling, persistence, and research.

The repository's GitHub description still advertises Whisper, Docker, and a web dashboard. The current product already has SwiftUI, Parakeet, an encrypted journal, an explicit research Task mode, and authenticated Unix sockets. Keep this foundation and simplify its contracts before taking on a second harness or runtime.

## Data flow and audit findings

| Area | What the source does today | Implemented here and remaining work |
| --- | --- | --- |
| Native workflow | The composer separates conversation from authorization-gated Tasks. Scope and commands were concealed in collapsible cards. In-flight sends could steal navigation or overwrite a new draft. | Scope and commands are visible at authorization. The composer exposes its verb and keyboard focus, honors Reduce Motion, and preserves text on failed sends. Add a reconnect-aware follow-latest control, keyboard walkthrough, and user-visible error recovery for each panel. |
| Speech and transcription | Swift captures and renders audio. Framed PCM goes to Python for Silero endpointing and final Parakeet transcription. TTS sends PCM back to the native player. The capture path avoids storing raw mic audio. | The final transcript can be copied explicitly. Next, implement Dictation as its own capture intent. Deliver the transcript to an editable preview, bypass LLM and TTS, and let the operator copy, save, or submit it. Add provisional text only with an actual streaming STT backend and separate provisional sequence from final history. |
| Local IPC | Each UI request connects and authenticates; command and event actors are separate. Heavy calls could occupy the same actor as Stop. Audio had its own implementation of Unix socket opening. | Stop and hands-free controls have a separate client. Audio and command connections share socket setup and disconnected-write handling. Next, define typed envelopes with request IDs, deadlines, generation, and typed failures. Move planning and import behind immediate acknowledgements with progress events. Preserve snapshot and cursor recovery for lost responses. |
| Research harness | The durable engine queues, authorizes, executes read capabilities through one-use receipts, and evaluates accumulated results. Dependencies are already represented in persisted records. The planner has limited dependency and evidence semantics. | Paused tasks can stop immediately, preserving completed work. Pause uses the persisted state and transient reads back off. Replans filter duplicate steps and respect the remaining budget. Next, add validated dependency references and per-step evidence checks, distinguish empty evidence from successful research, and tie claims to source IDs before displaying a synthesis. |
| Native actions | The production broker permits research reads. The native app already owns user permissions. | Mac Actions opens a user-selected app via Launch Services and reveals MacBot's data folder in Finder. These actions require a direct click. Next, connect typed action proposals to native authorization and result receipts. Start with open-app and reveal-item. Add focused-window reads and then specific Accessibility actions after permission and target-verification tests. |
| Library and retrieval | Documents are committed in SQLite; ingestion and queries share a pinned MiniLM encoder and a rebuildable vector index. Document import crosses JSON as base64 and runs a bounded parsing subprocess. | Keep SQLite authoritative. Profile import copies and UI responsiveness before switching to a bounded fd or spool transfer. Any embedder change needs a separate index revision, dimension and identity checks, dual rebuild evaluation, and atomic activation with rollback. |
| Network research | Web fetch validates resolved addresses before a separate HTTP client request. | Connection-time address validation remains open. Pin each approved connection and redirect to its validated public address while preserving TLS hostname checks. Keep this a prerequisite to broadening automatic web fetch. |
| Provisioning and release | Catalog hashes, runtime model choices, and paired app/runtime generations exist. Setup duplicated the model list, artifact staging could race, and users could mistake an old model run for current acceptance. | Release provisioning follows the manifest. Per-artifact locks serialize downloads/conversion and explicit verification rehashes files. Benchmark output refuses overwrite and records context length and time-to-first-output coverage. Still qualify paired rollback, generation pruning, exact revision/offline startup, and installed permissions. |
| Latency and memory | Model token profiles, prompt reuse, bounded queues, playback generations, and a residency lease already exist. Historical sampled RSS and text TTFT describe individual probes. | Compare capture-to-endpoint, STT, inference queue, first useful text, first synthesized sample, audible onset, and Stop acknowledgement separately. Report p50/p95, cold and warm, under active talk and background Task work. Track peak unified-memory pressure alongside RSS and report dropped frames, thermal drift, and cancellation tails. |

Audio should continue to bypass JSON. Keep one live audio owner and bounded pass-through with turn and playback generation IDs. Advance the generation on interrupt and discard late PCM for older generations. Keep cancellation acknowledgements independent of task planning, document import, and event polling. When measuring, record sample-rate conversions, copy count, queue residence, and audio overruns before considering shared memory.

## Model and quantization matrix

Keep the five pinned production roles during software work. The existing [model screening](MODEL_SCREENING.md) has historical Apple Silicon measurements, including a faster first synthesized chunk for the 0.6B Aiden candidate. That comparison leaves voice preference and audible end-to-end latency open. A candidate must pass its role's gates before joining the release manifest.

| --- | --- | --- |
| LLM | Official Qwen3.5-2B, locally converted Q4_K_M GGUF on pinned llama.cpp Metal | Run 8K and 16K with the same text-only prompt, schema, and answer cap. Compare the 2B GGUF with the registered 2B MLX 4-bit and LFM2.5-1.2B GGUF for latency and memory. Add official Qwen3.5-4B via local text-only conversion as a quality candidate, and preserve the historical Qwen3-4B-Instruct-2507 comparison. [Qwen3 Embedding](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B) |
| VAD | Silero ONNX | Keep Silero as the baseline and compare a compatible Silero Core ML build as a backend tradeoff. Measure false starts, clipped initials, missed quiet speech, wake noise, and headset echo. Vary endpoint policy separately from backend and VAD threshold. [Silero](https://github.com/snakers4/silero-vad) · [FluidAudio](https://github.com/FluidInference/FluidAudio) |

Use the existing benchmark scripts for isolated screening, then the full Task, speech, and release gates in [VERIFICATION.md](VERIFICATION.md). Use the same clean and noisy fixtures for every STT candidate, and an untouched research holdout for final selection. Run candidates serially behind the residency lease. Record quantizer and runtime revisions, context settings, measured memory, and actual outputs. A faster model or a smaller weight file alone gives no evidence about end-to-end voice behavior.

Change one inference variable at a time. Start with official Qwen 2B Q4_K_M at 8K and 16K. On the better context setting, compare Q4_K_M with Q5_K_M from the same source and converter. Check the pinned runtime's support before comparing FP16 and Q8_0 KV caches, and record recurrent state separately where present. Screen Gemma 4 E2B as a multimodal alternative only for a separate screenshot-understanding experiment. Keep the initial desktop tools grounded in typed OS targets. [Gemma 4 E2B](https://huggingface.co/google/gemma-4-E2B-it) · [llama.cpp](https://github.com/ggml-org/llama.cpp)

Pipecat's pipeline and interruption design are useful references for bounded streaming. Pi's event and cancellation interfaces are useful for the Task kernel. Hermes covers broader memory, skills, and execution; integrating it would duplicate the owned journal and authorization boundary. Use the reference projects to compare behavior and keep one owner for each operation in MacBot. [Pipecat](https://github.com/pipecat-ai/pipecat) · [Pi](https://github.com/earendil-works/pi) · [Hermes](https://github.com/NousResearch/hermes-agent)

## Implementation order

1. **Wire and presentation.** Land software fixes, keep the wire contract compatible, and add request-level telemetry. Then introduce typed requests and versioned event payloads covering chat, capture, task, library, and settings. Test lost acknowledgements, reconnect during generation, stop during import, and stale responses.
2. **Transcription and research.** Ship an editable dictation flow; complete dependency handling and structured evidence evaluation in the durable Task engine. Use one fast path for text chat and an explicit queue for longer work. Bound token and time budgets per stage to reserve headroom for Stop and speech.
3. **Real Mac capabilities.** Add a narrow typed action allowlist. Resolve user-approved app identifiers to native targets immediately before execution. Bind the receipt to the operation, exact target, input, deadline, owner generation, and authorization revision. Report observed effects and preserve an explicit unknown outcome when an action may have executed before a disconnect. Keep arbitrary commands, filesystem writes, and unrestricted UI automation outside this initial action set.
4. **Model and audio selection.** Run the matrix with the same prompts, fixtures, comparison windows, and measured hardware budgets. Promote individual artifacts after their gates pass and rerun the entire pipeline on the exact resulting manifest.
5. **Release acceptance.** Test the installed artifact with no external network, paired lifecycle and rollback, physical route switching and barge-in, VoiceOver and keyboard navigation, blinded listening, and long idle/wake soak. Record the exact revision and installation generation.

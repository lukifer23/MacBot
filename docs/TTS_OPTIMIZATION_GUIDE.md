# Speech documentation index

[ARCHITECTURE.md](ARCHITECTURE.md). Production voice configuration belongs in
[CONFIGURATION.md](CONFIGURATION.md). Dated model measurements belong in
[MODEL_SCREENING.md](MODEL_SCREENING.md), and every listener, physical-latency,
memory, route-change, interruption, and endurance requirement belongs in
[VERIFICATION.md](VERIFICATION.md).

the current native-audio, single-Parakeet, Qwen-TTS path.

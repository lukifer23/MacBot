# Modernization status

The supported architecture and setup are documented in the [README](../README.md). The previous duplicated browser/native pipelines and event buses are replaced by an assistant-owned turn runtime with a bounded event journal, native shared-engine audio, resident speech models, authenticated adapters and explicit tool approvals.

Implementation is not release acceptance. Consult [verification](VERIFICATION.md) for tests, candidate measurements, physical-device checks and outstanding listening gates. Unsupported speed and production-readiness claims are not retained.

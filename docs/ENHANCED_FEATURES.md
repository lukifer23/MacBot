# Modernization status

The supported architecture and setup are documented in the [README](../README.md). The previous duplicated browser/native product paths are replaced by one SwiftUI operator surface with five destinations, an assistant-owned turn runtime with a bounded event journal, Swift-owned audio, one Parakeet final recognizer, a capability-driven Tasks destination, and read-only browser diagnostics.

Implementation is not release acceptance. Consult [verification](VERIFICATION.md) for tests, candidate measurements, physical-device checks and outstanding listening gates. Unsupported speed and production-readiness claims are not retained.
